# Read My Markdown

在 Chrome / Edge 中阅读本地 Markdown：无限层级文件树、代码高亮、Mermaid、居中 / 全宽阅读、可调宽双侧栏与阅读进度恢复。免费使用，文档在本机处理。

## 下载与安装

**[下载最新版本与查看安装步骤](https://github.com/ChaosLcc/ReadMyMarkdown/releases/latest)**

请在 Release 的 Assets 中下载 `read-my-markdown-版本号.zip`，不要使用 GitHub 自动生成的 Source code 压缩包。

1. 下载并解压 ZIP 到长期保留的文件夹。
2. 在 Chrome 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`），开启开发者模式。
3. 点击“加载已解压的扩展程序”（Edge 为“加载解压缩的扩展”），选择直接包含 `manifest.json` 的文件夹。
4. 在扩展详情开启“允许访问文件网址”，以预览直接拖入浏览器的本地 Markdown。
5. 点击扩展图标，选择或拖入 Markdown 文件 / 文件夹，开始阅读。

请保留安装文件夹。此方式需要手动更新：关闭阅读器，将新版替换到原来的安装文件夹，然后到扩展管理页点击“重新加载”；不要先移除扩展或清除本地数据。

Release 附带 `INSTALL.zh-CN.md` 完整安装说明和 `SHA256SUMS.txt` 校验文件。
